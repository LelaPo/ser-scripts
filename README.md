# ser-scripts

небольшой набор готовых скриптов для scripted events reloaded (scp:sl).  
адаптировано под ser 1.0.0, с чистым синтаксисом, плавной cassie на русском и встроенными командами для тестов.

## что внутри

* **`scripts/customCoin.ser`** — хаотичная монетка при подбрасывании. умеет менять местами игроков, менять размер (великан со щитом или быстрый гномик), выдавать редкие конфеты, джейлбёрд или устраивать блэкаут.
* **`scripts/scp3114.ser`** — спавн скелета в начале раунда с шансом 15%. аккуратно заменяет случайного scp (кроме 079) и запускает студийное оповещение cassie с синхронными русскими субтитрами.

## как установить

1. скопируй нужные `.ser` файлы в директорию:  
   `LabAPI/configs/Scripted Events Reloaded/`
2. в консоли сервера напиши `serreload` (или начни новый раунд).

## команды для проверки

можно вводить прямо в игровой консоли на `~` или в remote admin:

* `.scp3114` — превращает тебя в скелета и проигрывает cassie
* `.scp3114 random` — симулирует выбор случайного scp из раунда
* `.testcoin <число или слово>` — моментально запускает любой исход монетки (например, `.testcoin pink`, `.testcoin swap`, `.testcoin 8`)
* `.testcoin reset` — возвращает нормальный размер (1.0) и сбрасывает эффекты

## документация
