FormatDuration
==============

Formats a duration into a special format.
Here are some examples: 

#1) "HH:SS"
Shows only minutes and seconds, perfect for round timers or cooldowns.
Result: 01:30

#2) "DD days, HH hours and MM minutes"
Creates a readable sentence. The system automatically handles the spaces and commas.
Result: 2 days, 04 hours and 15 minutes

#3) "MMm SSs FFFms"
Displays minutes, seconds, and milliseconds for pinpoint accuracy.
Result: 01m 22s 450ms

This method returns text value.
You can save it to a variable with a '$' prefix.
$myVariable = FormatDuration ...

This method expects the following arguments:
- duration to format argument
  - Expected value: Duration in format #ms, #s, #m, #h (e.g. 5s or 2m)

- format argument
  - Description: Use these tags to format your time: DD for days, HH for hours, MM for minutes, and SS for seconds. 
You can separate them with colons (:) or dashes (-).
  - Expected value: Any text e.g. "Hello, World!"

AddTeslaIgnoreRule
==================

Sets the players that will be ignored by a tesla.

This method expects the following arguments:
- players argument
  - Expected value: Player variable (e.g. @all, @classDPlayers)

- remove id optional argument
  - Description: The ID of the tesla ignore rule. This is to identify this specific tesla ignore rule if you later want to remove SPECIFICALLY it later. There can be multiple tesla ignore rules with the same ID.
  - Expected value: Any text e.g. "Hello, World!"
  - Default value/behavior: no rule id
    (use _ to keep the default)

- update optional argument
  - Description: Whether the rule should check for any changes regarding the 'players' argument. E.g. when you use 'players' = ClassD and 'update' = false, then the rule will NOT update when player roles change, meaning that when some ClassD becomes a Guard, their rule will STILL apply, even though they are no longer ClassD.
  - Expected value: bool (true or false) value
  - Default value/behavior: True
    (use _ to keep the default)

Audio.Load
==========

Loads an audio file into the audio player.
SER is using 'AudioPlayerApi' to manage audio. 
This method does not error using SER's system, most audio errors will be logged by AudioPlayerApi to the console.
Your .ogg file MUST BE:
- 48kHz
- single (mono) channel
- medium quality

This method expects the following arguments:
- file name argument
  - Description: The .ogg file name. SER searches all folders under its main data directory automatically - no need to provide a full path.
  - Expected value: Any text e.g. "Hello, World!"

- clip name argument
  - Description: This will be the name of the audio clip. Refer to this name when attempting to play audio.
  - Expected value: Any text e.g. "Hello, World!"

This method defines custom errors:
- File doesn't exist
- File is not of type 'ogg'
- More than one file with the same name exists
